# MGTA 461 — Web Mining and Recommender Systems (cross-listed CSE 258)

**4 units** · MSBA (Rady MS Business Analytics) · offered FA26, varies, varies, varies

## What this course covers

Current methods for data mining and predictive analytics with emphasis on real-world
datasets and building working systems: recommender systems, web mining, and putting
current machine learning research into practice.

## What you should be able to do afterwards

- building recommender systems
- large-scale data mining
- applied machine learning engineering

## Topics covered

recommender systems, web mining, collaborative filtering, predictive analytics, real-world datasets.

## Tools used
