# CSE 251A — Machine Learning: Learning Algorithms

**4 units** · CSE · offered varies, varies, varies

## What this course covers

Algorithms for supervised and unsupervised learning from data: maximum likelihood, log-
linear models including logistic regression, nearest neighbor methods, kernel methods,
decision trees, ensemble methods, optimization, topic models, neural networks, and
backpropagation.

## What you should be able to do afterwards

- rigorous ML theory and implementation
- deriving and implementing learning algorithms

## Topics covered

supervised learning, logistic regression, kernel methods, decision trees, ensemble methods, neural networks, optimization.

## Tools used

Python.

## Prerequisites

Graduate standing; strong math (linear algebra, probability) strongly advised.
